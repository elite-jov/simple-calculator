# Code of Conduct

## Our Commitment

The **simple-calculator** project welcomes contributors and users of all backgrounds and experience levels. We are committed to a respectful, inclusive, and harassment-free community.

## Expected Behavior

- Be courteous, patient, and constructive in discussions and code reviews.
- Respect different perspectives and experience levels.
- Give and receive feedback professionally, focusing on ideas and work rather than individuals.
- Take responsibility for mistakes and work to resolve disagreements productively.
- Respect privacy and avoid sharing others' personal information without permission.

## Unacceptable Behavior

- Harassment, discrimination, intimidation, or personal attacks.
- Insults, trolling, or deliberately disruptive conduct.
- Sexualized language or unwanted sexual attention.
- Publishing another person's private information without explicit consent.
- Any other behavior that would reasonably be considered inappropriate in a professional collaborative environment.

## Scope

This Code of Conduct applies to all project spaces, including GitHub issues, pull requests, discussions, code reviews, and other communications related to **simple-calculator**. It also applies when someone officially represents the project in public.

## Reporting Concerns

If you experience or witness unacceptable behavior, report it privately to the repository maintainer using a private contact method listed on the maintainer's GitHub profile or repository. **Maintainers should add a dedicated reporting email or private reporting channel before inviting external contributions.**

When reporting, include a description of the incident, relevant links or screenshots, and any other information that may help. Reports will be reviewed as discreetly as practicable, and privacy will be respected to the extent possible.

## Enforcement

Project maintainers may remove or edit inappropriate content, issue warnings, temporarily restrict participation, or permanently ban participants, depending on the severity and circumstances of a violation. Decisions will be made in good faith with an emphasis on fairness and community safety.

## Attribution

This Code of Conduct draws on the principles of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1, and is adapted for the **simple-calculator** project.
